# Dayflow

**Every workday, perfectly aligned.**

An HR management system built for the Odoo HackX brief — attendance, leave
and payroll as one connected record instead of three spreadsheets. Built
with Next.js, Supabase and Tailwind.

## Quick start

```bash
git clone https://github.com/roshannair-04/ODOO.git dayflow
cd dayflow
npm install
cp .env.example .env.local   # fill in your Supabase project's keys
npm run dev
```

First time setting up? **Read [PROJECT_GUIDE.md](./PROJECT_GUIDE.md)** —
it covers creating a Supabase project, running the database migrations,
seeding demo data, and where everything in the codebase lives. Don't skip
it; `npm install && npm run dev` alone won't get you a working app.
